# IOS_TestGameApplication

Xcode で iPhone 実機向けにビルドできるシューティングゲームの土台を用意しています。
画面遷移は以下の流れで実装済みです。

1. タイトル
2. 難易度選択
3. 機体選択
4. カウントダウン
5. バトル (雑魚→ボス)
6. ゲームオーバー / ミッション完了 → タイトルへ戻る

## Xcode での利用方法

1. Xcode で新規の **iOS App (SwiftUI)** プロジェクトを作成します。
2. このリポジトリ内の `ShootingGame` フォルダをそのままプロジェクトにドラッグ & ドロップします。
3. 既存の `ContentView.swift` と `App` エントリがある場合は、テンプレート側を削除してこちらに置き換えてください。
4. シミュレータや実機でビルドできます。

## 画面ごとのポイント

- **難易度選択**: 雑魚数、ボスHP、残機数を難易度ごとに設定。
- **機体選択**: 機体の説明を表示して選択。
- **カウントダウン**: 3 秒カウント後にバトル開始。
- **バトル**: 
  - 雑魚撃破後にボス登場。
  - ボス撃破、または残機 0 でゲームオーバー。

## 次の拡張アイデア

- 機体ごとのスキル差分 (速度 / 火力 / HP)。
